## Featured Projects

### 1. AgentPlane — Provider-Agnostic AI Gateway

> Reliable LLM routing, fault tolerance, and secure API key management.

- Architected an AI gateway with PostgreSQL-backed routing rules, weighted load balancing, model-based routing, and automatic failover across multiple LLM providers.
- Implemented resilient request forwarding with configurable timeouts, exponential-backoff retries, and passive circuit breakers.
- Designed secure API key management with cryptographically secure generation, hashed secret storage, indexed lookups, user-level identity mapping, key revocation, and usage tracking.

`Go` `PostgreSQL` `ClickHouse` `REST APIs` `HashiCorp Vault` `AWS Secrets Manager`

[**Repository →**](https://github.com/dexterhere04/AgentPlane)

### 2. AI Legal Advisor — Hybrid RAG over 37+ Indian Acts

> Retrieval quality measured with an evaluation pipeline.

- Combined semantic search, BM25, query expansion, and reranking to retrieve relevant provisions across 37+ Indian Acts.
- Built an evaluation harness using Hit@1, Hit@3, Hit@5, and Mean Reciprocal Rank (MRR) to measure retrieval performance.
- Developed a retrieval-backed legal question-answering system with a FastAPI service.

`Python` `ChromaDB` `FastAPI` `NLP` `RAG`

[**Repository →**](https://github.com/Janavee01/Legal_Advisor)

---

### 3. FloorPlan AI — 2D Plans to Furnished 3D Renders

> From architectural drawings to AI-generated interior scenes.

- Built a multi-pass OCR pipeline to extract room labels across different fonts and image conditions.
- Implemented custom Voronoi flood-fill segmentation for open-plan layouts without explicit walls.
- Integrated ControlNet and Stable Diffusion to generate furnished interior scenes.

`Python` `OpenCV` `PyTorch` `Stable Diffusion`

[**Repository →**](https://github.com/Janavee01/floorplan)
